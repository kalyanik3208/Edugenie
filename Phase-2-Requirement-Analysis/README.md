# Phase 2 - Requirement Analysis

## Project Name
Edugenie - Google Gemini Powered Learning Assistant

## 1. Functional Requirements

- The user can enter an educational question.
- The system can send the question to Google Gemini.
- The system can receive an AI-generated response.
- The system can display the response to the user.
- The user can clear the conversation.

## 2. Software Requirements

- Python
- Google Gemini API
- HTML
- CSS
- JavaScript
- Flask
- Visual Studio Code
- GitHub

## 3. Hardware Requirements

- Computer or Laptop
- Internet Connection
- Minimum 4 GB RAM

## 4. Users

The system is designed for students and learners who need
quick educational assistance.

## 5. Expected Requirements

The application should have a simple interface and provide
useful AI-generated responses to educational questions.
