# Phase 3 - Project Design

## Project Name
Edugenie - Google Gemini Powered Learning Assistant

## 1. System Architecture

The Edugenie system follows a simple architecture:

User
  ↓
Edugenie Web Interface
  ↓
Backend Application
  ↓
Google Gemini API
  ↓
AI Generated Response
  ↓
Edugenie Web Interface
  ↓
User

## 2. Working Process

1. The user opens the Edugenie application.
2. The user enters an educational question.
3. The question is sent to the backend.
4. The backend sends the question to Google Gemini.
5. Gemini processes the question and generates a response.
6. The response is displayed on the Edugenie interface.

## 3. User Interface Design

The application will contain:

- Project title
- Question input box
- Ask button
- AI response section
- Clear button

## 4. Design Goal

The interface is designed to be simple, clean and easy for
students to use.
