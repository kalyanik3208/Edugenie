# Phase 6 - Project Testing

## Project Name
Edugenie - Google Gemini Powered Learning Assistant

## 1. Testing Objectives

The application is tested to ensure that the main features work
correctly and provide proper responses.

## 2. Test Cases

| Test Case | Input | Expected Result |
|---|---|---|
| 1 | Educational question | AI provides an answer |
| 2 | Simple topic question | Simple explanation is displayed |
| 3 | Empty input | User is asked to enter a question |
| 4 | Clear button | Conversation is cleared |
| 5 | Multiple questions | Each question receives an AI response |

## 3. Testing Process

The application is tested locally using the Flask development
server. Different questions and application features are checked
to verify the system behaviour.

## 4. Testing Result

The major functions of the Edugenie application are tested to
verify that the system works as expected.

## 5. Conclusion

The testing process helps ensure that Edugenie provides proper
AI-generated responses and a simple user experience.
