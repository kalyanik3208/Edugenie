# Phase 7 - Project Documentation

## Project Name
Edugenie - Google Gemini Powered Learning Assistant

## 1. Project Overview

Edugenie is an AI-powered learning assistant developed using
Google Gemini. It helps students get quick answers and simple
explanations for educational questions.

## 2. Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API

## 3. Working

1. The user enters an educational question.
2. The question is sent to the backend.
3. The backend connects with Google Gemini API.
4. Gemini generates an AI-based response.
5. The response is displayed to the user.

## 4. Benefits

- Provides quick educational assistance.
- Gives simple explanations.
- Easy to use.
- Helps students understand topics.
- Available through a web interface.

## 5. Future Enhancements

- Voice-based questions
- Multiple language support
- Quiz generation
- Study plan generation
- Improved user interface

## 6. Conclusion

Edugenie provides a simple AI-powered learning experience
for students using Google Gemini technology.
