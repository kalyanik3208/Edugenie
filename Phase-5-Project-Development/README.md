# Phase 5 - Project Development

## Project Name
Edugenie - Google Gemini Powered Learning Assistant

## 1. Development Overview

Edugenie is developed as a web-based AI learning assistant
using Python, Flask and Google Gemini API.

## 2. Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- Google Gemini API
- Visual Studio Code

## 3. Project Structure

The project contains the following main files:

- app.py - Backend application
- index.html - User interface
- style.css - User interface styling
- script.js - Frontend interaction
- requirements.txt - Required Python packages

## 4. Development Process

1. Created the Flask application.
2. Designed the Edugenie user interface.
3. Connected the application with Google Gemini API.
4. Implemented educational question processing.
5. Displayed AI-generated responses to the user.
6. Added a clear conversation feature.
7. Tested the application locally.

## 5. Application Features

- Educational question input
- AI-generated answers
- Simple explanations
- Interactive web interface
- Clear conversation option

## 6. Development Result

The Edugenie application was successfully developed as an
AI-powered learning assistant using Google Gemini technology.
